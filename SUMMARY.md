# Homey PalGate Opener - Summary

## What Changed

This document summarizes the updates made to integrate proper token generation from the pylgate library.

## Key Updates

### 1. Token Generator ([lib/tokenGenerator.js](lib/tokenGenerator.js))

- **Complete rewrite** to match the pylgate Python implementation
- Fixed T_C_KEY constant to use correct values from pylgate
- Fixed timestamp offset (2 seconds instead of incorrect 946684800)
- Implemented proper AES-128 encryption matching pylgate's compact implementation
- Fixed phone number encoding using BigInt for values > 32 bits
- Changed output format from Base64 to uppercase hexadecimal

### 2. Helper Scripts

Three new scripts to assist users:

#### [get-token.js](get-token.js)

- Automates the Device Linking process
- Generates QR code for scanning with PalGate app
- Polls the API and retrieves session token automatically
- Displays phone number, session token, and token type

#### [test-credentials.js](test-credentials.js)

- Validates credentials before using them in Homey
- Tests API authentication
- Confirms token generation is working correctly
- Provides troubleshooting guidance

#### Purpose

These scripts solve the main user pain point: **"How do I get a session token?"**

## Technical Details

### Token Generation Algorithm

The token generation now exactly matches pylgate:

1. **Step 1**: AES encryption of session token with derived key
   - Derive key from T_C_KEY + phone number
   - Encrypt session token (16 bytes)

2. **Step 2**: AES decryption with timestamp
   - Create state with timestamp + offset
   - Decrypt using result from Step 1 as key

3. **Assembly**: Combine into 23-byte token
   - Byte 0: Token type (0x01/0x11/0x21)
   - Bytes 1-6: Phone number encoded
   - Bytes 7-22: Encrypted component from Step 2

4. **Output**: Uppercase hexadecimal string (46 characters)

Tokens generated by JavaScript now match Python pylgate exactly:

## User Experience Improvements

### Before

- Users had to manually extract session tokens (complex)
- No guidance on how to get tokens
- Trial and error with token types
- No way to test if credentials work

### After

- **Simple process**: Run `node get-token.js`, scan QR code, done
- **Validation**: Run `node test-credentials.js` to verify before setup
- **Clear documentation**: Step-by-step guides with troubleshooting
- **Better UX**: Helpful placeholders and instructions in pairing flow
